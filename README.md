# toddlerbot-NYCU

A fork of toddlerbot documenting the replication process, technical notes, and local modifications at NYCU, ROC(Taiwan).

這是一個 toddlerbot 的分支，記錄在中華民國國立陽明交通大學復現時，復現的過程、技術筆記，與一些本地的修改。

## Branches／分支
- `nycu-dev`: Contain NYCU-specific modifications and the replication and future development notes.
- `main`: Stay sync'ed with the upstream (the official main branch).
- `feat/*` and `fix/*`: Created to contain a new feature or fix. A pull request will be created to submit the changes to the upstream.

- `nycu-dev`：儲存我們特有的修改，與一些復現和未來開發筆記。
- `main`：與上游（官方 Main 分支）保持同步。
- `feat/*` 與 `fix/*`：當我們要建立一個 Pull Request 以把新更動傳到上游時，我們會建立這種分支。
